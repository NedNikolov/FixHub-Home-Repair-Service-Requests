# FixHub Home Repair Service Requests

FixHub is a Vite + React + TypeScript starter for a home repair services site. It includes Bootstrap, a clean source structure, and a polished landing page you can extend into a booking flow or full business site.

## Included structure

- `src/components` for reusable UI pieces
- `src/layouts` for page shells and shared wrappers
- `src/pages` for route-level screens
- `src/data` for seeded content and static models
- `src/hooks` for React hooks
- `src/styles` for global styles
- `src/assets` for images and media
- `src/utils` for shared helpers

## Getting started

1. Install dependencies:
	```bash
	npm install
	```
2. Start the dev server:
	```bash
	npm run dev
	```
3. Build for production:
	```bash
	npm run build
	```

## Notes

- Bootstrap is imported from `src/main.tsx`.
- Global theme and layout styling live in `src/styles/index.css`.
- The starter homepage is in `src/pages/HomePage.tsx`.
